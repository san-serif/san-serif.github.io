Every hint so far about native versus Sino-Korean numbers pays off here. The hour uses native numbers, the same ones from One, Please: 한 시, 두 시, 열두 시. The minutes switch to Sino-Korean, the Counting Won set: 일 분, 이십 분, 오십구 분. One clock, two number systems, and no way around learning both.

<Hint>This is the one sentence where the two number systems actually collide: 여덟 시 이십 분 (8:20) is native Korean for the hour immediately followed by Sino-Korean for the minutes, in the same breath. There's no partial credit for mixing them up, native numbers never label minutes and Sino-Korean numbers never label the hour.</Hint>

### From, Until, When It Starts

부터 (from) and 까지 (until) bracket a time range. 시 attaches straight to the hour for a single point in time.

<SentenceBlock formal="수업이 일곱 시부터 아홉 시까지 있습니다." formalRom="sueobi ilgop sibuteo ahop sikkaji isseumnida." polite="수업이 일곱 시부터 아홉 시까지 있어요." politeRom="sueobi ilgop sibuteo ahop sikkaji isseoyo." casual="수업이 일곱 시부터 아홉 시까지 있어." casualRom="sueobi ilgop sibuteo ahop sikkaji isseo." english="Class is from 7 to 9." />

<SentenceBlock formal="점심을 열두 시에 먹습니다." formalRom="jeomsimeul yeoldu sie meokseumnida." polite="점심을 열두 시에 먹어요." politeRom="jeomsimeul yeoldu sie meogeoyo." casual="점심을 열두 시에 먹어." casualRom="jeomsimeul yeoldu sie meogeo." english="I eat lunch at 12." />

<SentenceBlock formal="영화가 몇 시에 시작합니까?" formalRom="yeonghwaga myeot sie sijakhamnikka?" polite="영화가 몇 시에 시작해요?" politeRom="yeonghwaga myeot sie sijakhaeyo?" casual="영화가 몇 시에 시작해?" casualRom="yeonghwaga myeot sie sijakhae?" english="What time does the movie start?" />

<Hint>오전/오후 (AM/PM) mostly shows up when there's real ambiguity, a train schedule, an exam time, a formal appointment. In everyday conversation Koreans lean on context the same way English speakers do: "meet you at 7" doesn't need "PM" attached if it's obviously evening.</Hint>
