-아서/-어서 glues a reason onto a result in one sentence: [reason] + 아서/어서 + [what happened because of it]. It runs on the exact same vowel-harmony split as everything else you've conjugated so far, ㅏ or ㅗ takes 아서, everything else takes 어서.

<SentenceBlock formal="비가 와서 우산을 샀습니다." formalRom="biga waseo usaneul satseumnida." polite="비가 와서 우산을 샀어요." politeRom="biga waseo usaneul sasseoyo." casual="비가 와서 우산을 샀어." casualRom="biga waseo usaneul sasseo." english="It rained, so I bought an umbrella." />

<SentenceBlock formal="좀 비싸서 안 샀습니다." formalRom="jom bissaseo an satseumnida." polite="좀 비싸서 안 샀어요." politeRom="jom bissaseo an sasseoyo." casual="좀 비싸서 안 샀어." casualRom="jom bissaseo an sasseo." english="It was a bit expensive, so I didn't buy it." />

<SentenceBlock formal="피곤해서 아침에 늦게 일어났습니다." formalRom="pigonhaeseo achime neutge ireonatseumnida." polite="피곤해서 아침에 늦게 일어났어요." politeRom="pigonhaeseo achime neutge ireonasseoyo." casual="피곤해서 아침에 늦게 일어났어." casualRom="pigonhaeseo achime neutge ireonasseo." english="I was tired, so I woke up late in the morning." />

<Hint>If you can already conjugate a verb into -아요/-어요, you already know whether it takes -아서 or -어서, same split, same logic. There's no separate rule to memorize here, just the familiar one applied to a new ending.</Hint>

<SentenceBlock formal="친구 생일이어서 친구 집에 갑니다." formalRom="chingu saengirieoseo chingu jibe gamnida." polite="친구 생일이어서 친구 집에 가요." politeRom="chingu saengirieoseo chingu jibe gayo." casual="친구 생일이어서 친구 집에 가." casualRom="chingu saengirieoseo chingu jibe ga." english="Because it's my friend's birthday, I'm going to their house." />

<SentenceBlock formal="한국 친구가 있어서 한국어를 공부합니다." formalRom="hanguk chinguga isseoseo hangugeoreul gongbuhamnida." polite="한국 친구가 있어서 한국어를 공부해요." politeRom="hanguk chinguga isseoseo hangugeoreul gongbuhaeyo." casual="한국 친구가 있어서 한국어를 공부해." casualRom="hanguk chinguga isseoseo hangugeoreul gongbuhae." english="I study Korean because I have a Korean friend." />

<SentenceBlock formal="날씨가 좋아서 산책하러 갑니다." formalRom="nalssiga joaseo sanchaekhareo gamnida." polite="날씨가 좋아서 산책하러 가요." politeRom="nalssiga joaseo sanchaekhareo gayo." casual="날씨가 좋아서 산책하러 가." casualRom="nalssiga joaseo sanchaekhareo ga." english="The weather is good, so I'm going for a walk." />

<SentenceBlock formal="커피를 많이 마셔서 잠을 못 잡니다." formalRom="keopireul mani masyeoseo jameul mot jamnida." polite="커피를 많이 마셔서 잠을 못 자요." politeRom="keopireul mani masyeoseo jameul mot jayo." casual="커피를 많이 마셔서 잠을 못 자." casualRom="keopireul mani masyeoseo jameul mot ja." english="I drank a lot of coffee, so I can't sleep." />

<Hint>One quirk to file away: -아서/-어서 can't lead into a command or a suggestion. You won't see it directly in front of -세요 or -ㄹ까요; Korean reaches for a different reason-connector in those cases, one you'll meet in a later lesson.</Hint>
