“Even if we miss the first bus, we’ll still get there.” 就算……也…… accepts a possible setback, then holds the outcome steady. 就是……也…… can make the same point more emphatically; the main clause tells what still stands.

<CSentenceBlock simplified="就算没有人陪我，我也要去看这部电影。" traditional="就算沒有人陪我，我也要去看這部電影。" pinyin="jiùsuàn méiyǒu rén péi wǒ, wǒ yě yào qù kàn zhè bù diànyǐng." jyutping="zau6 syun3 mut6 jau5 jan4 pui4 ngo5, ngo5 jaa5 jiu3 heoi3 hon3 ze2 bou6 din6 jing2" english="Even if no one goes with me, I still want to see this movie." />

<CSentenceBlock simplified="那就是我等的人。" traditional="那就是我等的人。" pinyin="nà jiù shì wǒ děng de rén。" jyutping="naa5 zau6 si6 ngo5 dang2 dik1 jan4。" english="That’s the person I’m waiting for." />

<CSentenceBlock simplified="我也不是。" traditional="我也不是。" pinyin="wǒ yě bùshì。" jyutping="ngo5 jaa5 bat1 si6。" english="Nor am I." />
