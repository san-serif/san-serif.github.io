“Even if it rains, we’re going.” 哪怕……也…… raises a possible obstacle, then keeps the result in place. The second clause is what the speaker is sticking with.

<CSentenceBlock simplified="哪怕很难，我也会试一试。" traditional="哪怕很難，我也會試一試。" pinyin="nǎpà hěn nán， wǒ yě huì shì yí shì。" jyutping="naa5 paa3 han2 naan4， ngo5 jaa5 wui5 si3 jat1 si3。" english="Even if it’s difficult, I’ll give it a try." />

<CSentenceBlock simplified="哪怕只剩十分钟，我们也要把重要的部分讲完。" traditional="哪怕只剩十分鐘，我們也要把重要的部分講完。" pinyin="nǎpà zhǐ shèng shí fēnzhōng, wǒmen yě yào bǎ zhòngyào de bùfen jiǎng wán." jyutping="naa5 paa3 zi2 sing6 sap6 fan1 zung1, ngo5 mun4 jaa5 jiu3 baa2 zung6 jiu3 dik1 bou6 fan6 gong2 jyun4." english="Even if only ten minutes are left, we still need to finish the important part." />

<CSentenceBlock simplified="哪怕大家意见不一样，我们也可以先听完再讨论。" traditional="哪怕大家意見不一樣，我們也可以先聽完再討論。" pinyin="nǎpà dàjiā yìjiàn bù yíyàng, wǒmen yě kěyǐ xiān tīng wán zài tǎolùn." jyutping="naa5 paa3 daai6 gaa1 ji3 gin3 bat1 jat1 joeng6, ngo5 mun4 jaa5 ho2 ji5 sin1 teng1 jyun4 zoi3 tou2 leon6." english="Even if we disagree, we can listen to everyone first and discuss it afterward." />
