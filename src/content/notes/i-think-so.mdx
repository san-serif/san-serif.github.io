The sky is dark, and you’re guessing it will rain: 비가 올 것 같아요. 것 같아요 presents an impression or prediction without making it sound certain. The form before 것 changes with the word and tense.

<SentenceBlock formal="기분이 좋은 것 같습니다." formalRom="gibuni joeun geot gatseumnida." polite="기분이 좋은 것 같아요." politeRom="gibuni joeun geot gatayo." casual="기분이 좋은 것 같아." casualRom="gibuni joeun geot gata." english="It seems like they are in a good mood." />

<SentenceBlock formal="안나 씨가 집에 간 것 같습니다." formalRom="anna ssiga jibe gan geot gatseumnida." polite="안나 씨가 집에 간 것 같아요." politeRom="anna ssiga jibe gan geot gatayo." casual="안나 씨가 집에 간 것 같아." casualRom="anna ssiga jibe gan geot gata." english="I think Anna went home." />

<Hint type="hint">Here are the main shapes side by side: 먹는 것 같아요 (seems to eat/is eating), 먹은 것 같아요 (seems to have eaten), 맛있는 것 같아요 (seems delicious), and 맛있을 것 같아요 (seems it will be delicious). The tense sits before 것.</Hint>

<SentenceBlock formal="이번 시험은 어려울 것 같습니다." formalRom="ibeon siheomeun eoryeoul geot gatseumnida." polite="이번 시험은 어려울 것 같아요." politeRom="ibeon siheomeun eoryeoul geot gatayo." casual="이번 시험은 어려울 것 같아." casualRom="ibeon siheomeun eoryeoul geot gata." english="I think this exam will be difficult." />

<Hint type="insight">In real life, 것 같아요 is also a polite way to soften an opinion or answer when you're not fully certain. It can signal a genuine guess, or simply make a statement sound less blunt; the surrounding context tells you which.</Hint>
