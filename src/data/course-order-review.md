# Course order review

Reviewed 2026-10-24. `order` is a suggested learning sequence **within each level**, not an official exam question order. Every level now has unique, consecutive order values, and the same sequence drives the course list and lesson Previous/Next links.

## Beginner path

- **Japanese N5:** Starts with greetings, self introduction, and a polite noun sentence. Existence with ある・いる follows, then possession, questions, object and place particles, and later て-form constructions. The greeting lesson fills a missing entry point; its source is conversational usage rather than a JLPT grammar record.
- **Korean TOPIK I:** Starts with greetings and introductions, then topic marking, identity negation, information focus, and existence/location. The greeting lesson was already present but had an unused order value before it.
- **Chinese HSK 1:** Starts with greetings, 是 identity, basic sentence order, and 有 possession/existence. Counting, pointing, and questions come before more complex aspect and comparison topics. The greeting lesson has no `sourceRecords` because it is an orientation lesson, not a record in the grammar crosswalk.

## Later levels

- **Japanese N4:** Opens with topic/focus, movement, and approximate quantities before giving/receiving and more complex clauses.
- **Japanese N3:** Uses source-record order as a stable starting point for advanced topics. **N2 and N1** follow thematic progressions through time/change, conditions, comparison, scope, and formal usage. These are editorial groupings, not strict grammar prerequisites.
- **Chinese HSK 2–6 and 7–9:** Follow the lesson numbers in the topic-grouped curriculum map. This removes several misplaced HSK 3 lessons and two HSK 7–9 additions that were colliding with earlier order numbers. The later levels are organized by topic; learners can open a specific point without completing every preceding lesson.
- **Korean TOPIK II:** Contains only two lessons. Its current order is consistent, but the level is not a complete intermediate course.

The HSK grammar crosswalk still covers all 573 source IDs exactly once. Reordering does not change source coverage or saved progress, which is keyed by lesson ID.
